# Brother Zone — Workforce & Technical Solutions

A responsive, static multi-page website built with plain HTML, CSS and JavaScript. No Bolt branding, watermark, Bolt dependency, build step or paid framework is included.

## Files
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `careers.html` — Careers
- `contact.html` — Contact
- `assets/css/style.css` — Styles
- `assets/js/main.js` — Navigation and contact email helper
- `.nojekyll` — Keeps GitHub Pages from applying Jekyll processing

## Publish on GitHub Pages
1. Create a GitHub repository (for example, `brother-zone-website`).
2. Upload the contents of this folder. Ensure `index.html` is in the repository root, not inside another nested folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

## Important before going live
- The contact form opens the visitor's default email application; it does not store submissions on a server. A backend or form service is needed for direct online form submissions.
- The careers page currently invites applicants to email their CV to `mahp1646@gmail.com`.
- Review all business descriptions, service claims, email and address before publishing.
- The Google Fonts import requires internet access; system sans-serif fallbacks are included.
